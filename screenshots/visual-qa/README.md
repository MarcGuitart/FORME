# FORME visual QA captures

Captured with headless Chrome and the DevTools Protocol against the local static preview.

- Desktop viewport: 1440 × 1000
- Laptop viewport: 1280 × 900
- Mobile viewport emulation: 390 × 844, device scale factor 1
- Captures include Landing, Discovery, Archive, all six story routes, and the next-story hover state.
- Browser flow exercised: open first car → next story → browser back → browser forward → return to collection.

`final/desktop-stories-contact.png` and `final/mobile-stories-contact.png` provide overviews; individual story captures are also included as WebP files.
