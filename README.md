# FORME

FORME is an editorial automotive experience: a visual collection for the cars, design and stories worth spending time with.

## First slice

- Cinematic, responsive landing page.
- Filterable collection of six automotive icons.
- Editorial detail view for each car.
- Motion respects reduced-motion preferences.
- Static frontend with no backend or build step.

## Run locally

Open `index.html` in a browser or serve this folder with any static file server.

## Content and assets

The initial collection and copy live in `src/app.js`. Photography is loaded from Unsplash at runtime. Replace these URLs with cleared, locally managed assets before production. The stories intentionally avoid presenting unverified technical specifications as facts.
